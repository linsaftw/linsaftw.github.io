# JetBrains Mono

Self-hosted latin subset of JetBrains Mono, served as a variable WOFF2.

- Upstream: https://github.com/JetBrains/JetBrainsMono
- File: `jetbrains-mono.woff2` (latin subset, variable weights 400-800)
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`
- Source: Google Fonts CSS2 endpoint for `JetBrains Mono:wght@400;500;700;800`, latin block, fetched 2026-10-30.

The site uses the font for its existing monospace identity. No glyphs were added or modified.
