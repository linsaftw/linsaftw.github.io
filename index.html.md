# LinsaFTW — Minecraft Infrastructure Developer

> Juan Cruz Linsalata, known as LinsaFTW, is an Argentine Minecraft infrastructure developer and founder of ArkFlame Studios.

LinsaFTW builds Minecraft server software, Java plugins, proxy security tools, anti-exploit systems, anticheat systems, performance tooling, and product infrastructure under ArkFlame Studios.

## Persona analysis

- Builder: hands-on Java, Bukkit, Spigot, Paper, Folia, Velocity, BungeeCord, and PacketEvents work.
- Operator: focused on uptime, logs, compatibility, support, profiling, and production server failure modes.
- Founder: uses ArkFlame Studios as the business and product ecosystem around the technical work.
